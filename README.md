# Predictive-DLCBF

Code and experimental materials accompanying the paper:

**Flexible Safety Boundaries: Predictive Dynamic Control Barrier Functions for UAV Navigation in Dense Environments**

## Overview

This project investigates Predictive DLCBF-based UAV navigation in dense environments. This repository will provide the algorithm implementation and experimental videos accompanying the paper.

## Release Status

- Experimental videos are being released first.
- Source code will be added in a future update.

## Experimental Video

The video presents the experimental architecture, virtual obstacle environments, corresponding real-flight demonstrations, and control and state trajectories.
